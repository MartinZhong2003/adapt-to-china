# Adapt to China

An English-first practical life platform for foreigners in China, built and iterated with AI-assisted coding.

**Live site:** https://adapttochina.pages.dev

## Why I built it

Foreigners living in or moving to China often face fragmented information, language barriers, and local services that are difficult to verify in English. Adapt to China started as a practical attempt to make common tasks easier to navigate.

## What is included

- 151 static HTML pages
- 132 service / location listings across key newcomer scenarios
- Healthcare finder and hospital information
- Renting and moving guides
- Daily-life guides and first-72-hours guidance
- Halal and vegetarian food directories
- Personal support information and intake flows
- Structured JSON data used by the site

## Product traction

- 6 real paid orders generated from user demand
- International users reached through English content and community channels
- Product scope, pricing, and service boundaries iterated based on real user feedback

## How I built it

This project was developed through an AI-assisted workflow:

1. Identify a concrete user problem
2. Break the problem into pages, data, and user flows
3. Use AI coding tools to accelerate implementation
4. Review and debug the generated code
5. Deploy with Cloudflare Pages
6. Collect real user feedback and iterate

The current site is primarily built with **HTML, CSS, JavaScript, and JSON**, and deployed on **Cloudflare Pages**.

## What I learned

- Real user problems are more important than feature quantity
- AI can dramatically speed up implementation, but human validation is still necessary
- Product boundaries and pricing should evolve from user behavior, not assumptions
- Shipping, observing, and iterating is more valuable than polishing in isolation

## Repository notes

- Hospital and restaurant contact information in this repository is public-facing directory information used by the website.
- Internal operating notes and private customer information are intentionally excluded from this public repository.
- No API keys, passwords, or private customer records should be committed.

## Disclaimer

Adapt to China is an independent personal project. Information may change over time, so users should verify important details with the relevant official provider before relying on them. The site does not provide professional medical, legal, immigration, tax, or financial advice.
